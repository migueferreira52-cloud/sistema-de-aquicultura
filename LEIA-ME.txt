AQUICULTURA - PROJETO INTEGRADOR

COMO ABRIR
1. Extraia o ZIP e abra no VS Code a pasta que contém index.html.
2. No terminal, instale o Flask uma única vez:
   pip install flask
3. Inicie o projeto:
   python python/app.py
4. Abra http://127.0.0.1:5000 no navegador.
   Não abra o index.html por duplo clique. Não precisa de Live Server,
   XAMPP, MySQL ou Flask-CORS. Mantenha o terminal aberto.

ORGANIZAÇÃO
index.html: início do site
paginas/: cadastros e consultas HTML
css/style.css: aparência
js/script.js: Fetch e CRUD
python/models.py: classes das entidades
python/dao.py: acesso ao SQLite
python/app.py: entrega do site e rotas REST internas
requirements.txt: Flask, única dependência direta
banco/modelo_fisico.sql: único script SQL, com estrutura e consultas comentadas
banco/aquicultura.db: único banco de dados, criado no primeiro uso
documentacao/: modelos conceitual e lógico e explicação

O banco é iniciado vazio. Os cadastros, as 15 tabelas e os vínculos foram
mantidos. Os exemplos de consultas da disciplina de Banco de Dados estão
no final de modelo_fisico.sql, comentados para não executar na inicialização.

DADOS ANTERIORES
Se você já fez cadastros na versão SQLite anterior, feche o servidor antigo,
faça uma cópia do arquivo banco/aquicultura.db e coloque-a na pasta banco/
da nova versão antes de iniciar. A estrutura não foi alterada. Não envie
bancos com dados pessoais ao GitHub. Se não copiar, começa vazio.

APOSTILAS
POO: classes, DAO, SQLite, Flask e JSON.
DWS: Fetch, GET/POST/PUT/DELETE e DOM.
BD: PK/FK, JOIN, subconsultas e paginação.
A API é interna e continua necessária para cumprir POO/DWS. A entrega dos
arquivos HTML pelo Flask usa send_from_directory, um pequeno ajuste fora
dos exemplos das apostilas. O DAO preserva PRAGMA e executescript para
criação do banco e integridade dos relacionamentos.

API PÚBLICA VIACEP
Na página Fornecedores, digite um CEP (exemplo: 01001-000) e clique em
Buscar endereço. O JavaScript consulta o ViaCEP e preenche o campo
endereco já existente. Complete o número e o complemento manualmente.
O CEP serve apenas para consulta, sem criar outro campo no banco.
O endereço é gravado normalmente no cadastro ao clicar em Cadastrar.
A consulta externa precisa de internet; o CRUD local continua funcionando
sem internet, e o endereço também pode ser digitado manualmente.
O ViaCEP não substitui a API Flask interna. A estrutura do banco e os
três modelos continuam iguais. Referência: DWS, capítulo 2, página 5.
A integração adapta o exemplo de Fetch para o formulário de fornecedores.
