SISTEMA DE GESTÃO DE AQUICULTURA
================================
Projeto escolar — versão simplificada e revisada

1. Abra o XAMPP e inicie Apache e MySQL.
2. Acesse http://localhost/phpmyadmin e importe banco/banco.sql.
   O banco novo se chama aquicultura_escolar. Não apaga bancos antigos.
   O arquivo documentacao/03_modelo_fisico.sql é uma cópia idêntica.
   Importe apenas um dos dois arquivos.
3. Para a demonstração, importe banco/dados_teste.sql UMA VEZ no banco vazio.
   Os registros são fictícios; não são dados reais da fazenda.
4. Extraia o ZIP e abra a pasta aquicultura_organizado no VS Code.
   No terminal, execute:

   python -m pip install -r python/requirements.txt
   python python/app.py

5. Abra http://127.0.0.1:5000. Não abra o index.html diretamente.
6. No phpMyAdmin, abra aquicultura_escolar e execute as consultas de
   banco/consultas.sql na aba SQL, uma por vez.

ORGANIZAÇÃO
index.html     — página inicial na raiz
paginas/       — formulários HTML e consultas
css/           — estilo compartilhado
js/            — JavaScript e Fetch
python/        — Flask, DAO, validação e configuração
php/           — consulta complementar de lotes por PDO
banco/         — estrutura, dados de teste e consultas SQL
documentacao/  — modelos, UML e revisão

FLUXO DE CADASTRO
Espécies e tanques antes dos lotes; lotes antes dos planos de alimentação.
O registro de alimentação usa o ID do plano. Cadastre fornecedores e
funcionários antes de selecioná-los nos campos opcionais.
Cadastre clientes antes de vendas e, na tela Vendas, cadastre a venda
primeiro e depois seus itens. Uma venda pode ficar sem itens enquanto é
montada. Na manutenção, escolha um tanque OU um equipamento.

PHP OPCIONAL
Copie as pastas php/ e css/ para C:\xampp\htdocs\aquicultura_organizado.
Abra http://localhost/aquicultura_organizado/php/consulta.php.
A consulta utiliza o mesmo banco e não é necessária para o Flask funcionar.

ATENÇÃO
Não há migração automática dos dados das versões anteriores. O sistema
mantém o escopo original de cadastro e consulta, sem controle de estoque,
login, edição ou exclusão. Uso escolar/local. Caso a porta ou a senha do
MySQL seja diferente, altere python/app.py e php/consulta.php.
